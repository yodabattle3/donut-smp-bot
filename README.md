# Donut SMP Bot

A comprehensive Discord bot for managing Donut SMP-styled servers with extensive moderation, member management, and community features.

## Features

- 📋 **Member Management**: Roles, promotions, demotions, visibility settings
- 🔨 **Moderation**: Bans, kicks, timeouts, warnings, strikes, mutes
- 📝 **Applications**: Whitelist applications, blacklist management
- 🎫 **Ticket System**: Member support tickets with claiming and management
- 💰 **Economy**: Payments, staff debt tracking, vouching system
- 📊 **Leveling**: Member activity tracking and statistics
- 🛡️ **Admin Tools**: Slowmode, locks, sticky messages, purging
- 📢 **Announcements**: Ad posting, fun facts, polls
- 🔐 **Security**: Scammer tracking, leave of absence system

## Installation

1. Clone the repository
2. Install dependencies: `npm install`
3. Create `.env` file with your bot token and MongoDB URI
4. Run `npm start`

## Commands

See the `/help` command in Discord for a full list of available commands.
